# Contributing

Issues describing a missing use case, an ambiguous definition, a broken query, or a reproducible test are welcome.

For now, **please propose changes in an Issue rather than opening an unsolicited Pull Request**. The model assets originate from a KG OS project with AGPL/commercial licensing considerations; an explicit contribution/licensing policy must be established before external contributions can be accepted. This does not restrict lawful reuse under the repository's existing license.

A model proposal should name the actual use case, competency questions, stable entity identities, Node/Relationship structure, negative cases, minimal KG OS YAML, runnable Cypher and synthetic tests. State which assumptions require agent judgment rather than a database constraint.

No secrets, production Knowledge, private credentials, personal records or third-party proprietary model copies. Do not silently treat OWL/RDF semantics as if they were implemented by KG OS Property Graph. Each model is optional and must preserve existing user Ontology autonomy.
